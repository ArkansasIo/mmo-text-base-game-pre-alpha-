# In-Game Audio System

The game now has a browser-safe audio layer for authenticated gameplay. The system provides a command-center ambient track, a fleet-alert tension track, interface feedback, mission cues, combat warnings, research completion, market activity, and notification sounds.

## Audio assets

| Asset | Purpose |
|---|---|
| `command_center_ambient.mp3` | Looping strategic command-center music. |
| `fleet_alert_tension.mp3` | Tense fleet, PvP, and warfare music. |
| `mission_dispatch.wav` | Fleet, hyperspace, wormhole, patrol, and expedition dispatch cue. |
| `mission_success.wav` | Mission or operation success cue. |
| `combat_alert.wav` | Combat, raid, PvP, and warfare warning cue. |
| `research_complete.wav` | Research, blueprint, and technology cue. |
| `market_trade.wav` | Market and corporation trade cue. |
| `notification_ping.wav` | Notification and alert cue. |
| `ui_click.wav`, `ui_hover.wav`, `ui_confirm.wav`, `ui_warning.wav` | General interface feedback. |

## Runtime behavior

`js/game-audio.js` is loaded by the authenticated template. It stores mute and volume preferences in local storage, exposes an accessible Audio On/Off toggle and volume slider, catches browser autoplay rejections, and starts music after an allowed user interaction. `js/main.js` routes AJAX module actions into the audio manager, allowing navigation and gameplay commands to produce contextual cues without changing server-side behavior.

Combat and warfare terms switch to the fleet-alert music track. Fleet, hyperspace, wormhole, and expedition actions use the command-center track and dispatch cue. Research and blueprint actions use the research cue, while market actions use the trade cue. The sound manager throttles repeated effects to avoid rapid-click noise.

## Generation and verification

The short WAV effects are generated by `scripts/create_ui_sfx.py`. The music tracks are stored as MP3 files with their correct extensions so web servers provide the expected media type. `tests/audio_system_test.php` verifies all assets, local preference storage, autoplay-safe playback, action routing, authenticated controls, and AJAX integration. JavaScript syntax checks and the full PHP regression suite pass.
