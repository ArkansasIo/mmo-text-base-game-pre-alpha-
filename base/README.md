# base/

Core PHP classes and shared runtime logic.

## Key Files

- `Game.class.php`: primary gameplay and DB interaction surface.
- `User.class.php`: user session and account operations.
- `Chive.class.php`: DB connectivity layer.
- `functions.php`: common helper functions.
- `Debug.class.php`: debug output helpers.

Changes here affect multiple modules; validate broadly after edits.
