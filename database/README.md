# Database Backend Kit

This directory contains SQL assets and templates for the Stargate Wars backend lifecycle.

## Structure

- sql/: database creation, backend tables, views, and seed defaults
- excel_templates/: CSV headers for common data exports

## SQL Files

1. sql/01_create_database.sql
	- Creates database and grants privileges to app user.

2. sql/02_import_core_schema.sql
	- Imports the legacy game schema from game.sql.

3. sql/03_backend_tables.sql
	- Adds operational backend tables:
	  - app_migrations
	  - app_settings
	  - app_audit_log
	  - app_server_jobs
	  - app_daily_economy_metrics

4. sql/04_reporting_views.sql
	- Adds normalized reporting views:
	  - vw_player_core
	  - vw_player_economy
	  - vw_player_military

5. sql/05_seed_backend_defaults.sql
	- Seeds initial backend settings and migration keys.

## Recommended Execution Order

1. sql/01_create_database.sql (admin/root)
2. game.sql (core game schema)
3. sql/03_backend_tables.sql
4. sql/04_reporting_views.sql
5. sql/05_seed_backend_defaults.sql

## Automated Path

Use backend scripts from repository root:

```bash
./scripts/backend/db_init.sh      # full setup
./scripts/backend/db_migrate.sh   # backend layer only
```

## Excel Templates

- excel_templates/player_economy_template.csv
- excel_templates/player_military_template.csv

These templates match export formats generated by tools/backend/export_reports.php.
